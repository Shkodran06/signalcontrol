# SIGNALCONTROL

Sito web responsive per SIGNALCONTROL, marchio svizzero dedicato ai semafori intelligenti per cantieri. Lingue: tedesco, italiano e inglese.

## Anteprima locale

Scarica il repository e avvia nella cartella principale:

```sh
python3 -m http.server 8080
```

Apri http://localhost:8080. Nessuna compilazione o dipendenza necessaria.

## Pubblicazione

GitHub Pages: Settings → Pages → Deploy from a branch → main → / (root).

Per altri hosting statici, carica index.html, style.css, app.js e icon.svg nella radice web. Nessun dominio personalizzato è stato prenotato o collegato.
